## Month 3: June/July — Content + Launch
_Shoot everything, finalize, launch._

### Photography / Content Production
- [ ] Studio product shots (all 13 styles, multiple colorways)
- [ ] Lifestyle photography (people carrying bags, real-world settings)
- [ ] Flat lays (bag + contents, showing scale and utility)
- [ ] Process/behind-the-scenes shots (factory, fabrics, printing, stitching)
- [ ] Detail shots (labels, stitching, handles, fabric texture)
- [ ] Photos serve: website, catalog PDF, Instagram, ads — shoot once, use everywhere

### Instagram Launch
- [ ] Post 1: Brand announcement — logo reveal, "Alongway. Custom Bags, Made Simple."
- [ ] Post 2: The lineup — all 13 styles teaser
- [ ] Post 3: How it works — 3-step process
- [ ] Post 4-13: Individual style spotlights (1 per day or every other day)
- [ ] Reels: factory BTS, fabric selection, swatch kit unboxing
- [ ] Start following target accounts (brands that order custom bags)
- [ ] Engagement strategy: commenting, DMs to engaged followers
- [ ] Content cadence: 3-5 posts per week going forward

### Website Finalize
- [ ] Final QA — all pages, forms, pricing, mobile responsive
- [ ] Test form submissions end-to-end
- [ ] Speed optimization (image compression, lazy loading)
- [ ] Launch!

### Soft Launch (Week 1-2 of Month 3)
- [ ] Email existing OG clients who've ordered totes (Stanford, Boatsetter, Apteka)
- [ ] "We're launching something new" personal intro from Easton
- [ ] Offer swatch kit or sample to warm leads
- [ ] Goal: 3-5 orders before public launch

### Public Launch (Week 3-4 of Month 3)
- [ ] Announce on IG, email, and cross-promote from OG
- [ ] Meta ads start (IG + Facebook)
  - Target: small business owners, marketing managers, event planners
  - Creative: product shots + value props
  - Budget: $500-1,000/month to start
- [ ] Google ads (search)
  - Keywords: "custom tote bags," "custom branded totes," "custom bag manufacturer"
  - Budget: $500/month to start
- [ ] Cold email campaign to target industries
- [ ] LinkedIn outreach to marketing managers
