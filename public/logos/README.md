# Client logos

Drop one file per brand here and point to it in `data/brands.ts`.

- Prefer SVG. PNG is fine at 2x (at least 400px wide, transparent background).
- Single-color versions work best: the strip renders every logo in the same
  charcoal tint so the row reads as one set. Full-color files still work.
- Get the file from the brand's press or media kit, and confirm they are
  happy to be listed. A brand without a file shows as a text pill.
